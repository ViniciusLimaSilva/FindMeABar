# 🍻 FindMeABar

**FindMeABar** (interno: `bares_google`) é um MVP (Minimum Viable Product) desenvolvido em Flutter para ajudar usuários a encontrar os melhores bares com base em suas avaliações.

---

## 🚀 Sobre o Projeto

O projeto nasceu com o objetivo de simplificar a busca por lazer, utilizando a localização do usuário para listar bares próximos e destacar aqueles com as melhores notas. É a ferramenta ideal para quem quer descobrir novos lugares sem surpresas desagradáveis.

## ✨ Funcionalidades

- 📍 **Geolocalização:** Encontre bares exatamente onde você está.
- ⭐ **Avaliações:** Visualize as notas dos estabelecimentos para tomar a melhor decisão.
- 🔗 **Integração Externa:** Abra a localização no mapa ou entre em contato diretamente pelo app.
- 📱 **Interface Moderna:** Desenvolvido com Material Design para uma experiência fluida.

## 🛠️ Tecnologias Utilizadas

- [Flutter](https://flutter.dev/) - Framework UI.
- [Geolocator](https://pub.dev/packages/geolocator) - Para obtenção de coordenadas GPS.
- [HTTP](https://pub.dev/packages/http) - Para consumo de APIs de dados.
- [URL Launcher](https://pub.dev/packages/url_launcher) - Para abrir mapas e links externos.

## 📦 Como rodar o projeto

### Pré-requisitos
- Flutter SDK instalado.
- Emulador Android/iOS ou dispositivo físico conectado.

### Passo a passo
1. Clone o repositório:
   ```bash
   git clone https://github.com/ViniciusLimaSilva/FindMeABar.git
   ```
2. Entre na pasta do projeto:
   ```bash
   cd bares_google
   ```
3. Instale as dependências:
   ```bash
   flutter pub get
   ```
4. Execute o aplicativo:
   ```bash
   flutter run
   ```
